## Download

[GitHub Releases]()

### Availble versions:
**macOS**: Download `.dmg` file
**Windows**: Download `.exe` file
**Linux**: Download `.AppImage` file

## features

- Generate secure passwords
- Generate names (first and last)
- Generate usernames
- Generate company names
- Copy to clipboard

## installation
1. Download the correct version for your OS
2. Open the file and follow the installation instructions
3. Run the app. 

## development

### run locally:
\`\`\`bash
npm install
npm start
\`\`\`

### build for release:
\`\`\`bash
npm run build:mac    # macOS
npm run build:win    # Windows
npm run build:linux  # Linux
\`\`\`
